    1. プログラムを動かす準備¶

    • Wandbox で C 言語を始める
    • Codespaces で C 言語を始める
    • Windows で C 言語を始める
    • macOS で C 言語を始める
    • Ubuntu で C 言語を始める
    ターミナルのヒント（クリックで展開）

    ターミナルでコマンドを入力するときに役立つテクニックを紹介します。

    一度入力したコマンドの再利用¶

    • Up キーや Down キーを押すと、過去に入力したコマンドを呼び出して再利用できます

    Tab 補完¶

    • コマンド名、ファイル・ディレクトリ名を途中まで入力して Tab キーを押すと、残りを自動で補完します
    • 候補が複数ある場合、もう一度 Tab キーを押すと候補一覧が表示されることがあります

    コマンドの中断¶

    • 実行中のコマンドを中断したいときは、Ctrl+C を押します
