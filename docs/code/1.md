## 1.2

### 1.2.1

```c title="複数の puts 関数を使うコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
}
```

### 1.2.2

```c title="puts 関数の並びを入れ替えたコード"
#include <stdio.h>

int main()
{
	puts("Banana");
	puts("Apple");
}
```

### 1.2.3

```c title="puts 関数を増やしたコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
	puts("Cat");
}
```

### 1.2.4

```c title="インデントが不ぞろいなコード"
#include <stdio.h>

int main()
{
	puts("Apple");
 puts("Banana");
  puts("Cat");
puts("Dog");
}
```

```c title="インデントがそろっているコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
	puts("Cat");
	puts("Dog");
}
```

### 1.2.5

```c title="文字を並べて長方形を描くコード"
#include <stdio.h>

{
	puts("**********");
	puts("*        *");
	puts("*        *");
	puts("*        *");
	puts("**********");
}
```

```c title="文字を並べて三角形を描くコード"

int main()
{
	puts("    *");
	puts("   ***");
	puts("  *****");
	puts(" *******");
	puts("*********");
}
```

## 1.3

### 1.3.1

```c title="文字列の中で改行文字を使うコード"

{
	puts("He waited.\n\nNo one came.");

```

### 1.3.2

```c title="文字列の中でタブ空白を使うコード"

int main()
{
	puts("1\tJanuary");
	puts("2\tFebruary");
	puts("3\tMarch");
	puts("12\tDecember");
}
```

### 1.3.4

```c title="バックスラッシュを出力するコード"

{

```

### 1.3.5

```c title="エスケープシーケンスの練習"

{
```

```c title="タブ空白で整列された表を出力するコード"

}
```

## 1.4

### 1.4.1

```c title="❌ 誤り: 文末にセミコロン（;）がないコード"
{
	puts("Apple")
}
```

### 1.4.2

```c title="❌ 誤り: 必要なダブルクォーテーションがないコード"

	puts(Apple);
}
```

```c title="❌ 誤り: main 関数の閉じかっこ } がないコード"

	puts("Apple");
```

### 1.4.4

```c title="⚠️ 誤り: 存在しないエスケープシーケンスを使うコード"
}
```
