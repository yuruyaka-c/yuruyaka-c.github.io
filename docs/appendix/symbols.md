## コード中の記号の読み方・言い換え

- C 言語のコードに書かれた記号の読み方は、記号そのものの名称に限らない
- コード中では、文脈や言語（日本語・英語など）に応じて、別の読み方をされることがある
- 例えば `#` は、英語では音楽記号 `♯`（sharp）と区別して `hash` と呼ぶのが一般的だが、日本語では、どちらも「シャープ」と呼ばれることがある
- 記号の読み方には複数の言い方があり、唯一の正解があるとは限らない。人や場面によって読み方が異なることを、あらかじめ知っておくとよい

| コード | 日本語での読み方・言い換えの例 | 英語での読み方・言い換えの例 |
| :--- | --- | --- |
| `#include` | シャープ・インクルード / ハッシュ・インクルード | hash include / pound include |
| `!=` | ノットイコール | not equal / bang equal |
| `!a` | ノット・エー | not a / bang a |
| `++` | プラスプラス / プラプラ / インクリメント | plus plus / double plus / increment |
| `==` | イコールイコール / 等しい | equal equal / double equal |
| `<=` | 小なりイコール / 以下 | less than or equal / less equal |
| `>=` | 大なりイコール / 以上 | greater than or equal / greater equal |
| `||` | または / オア / オアオア / 論理オア | or / double pipe / logical or |
| `&&` | かつ / アンド / アンドアンド / 論理アンド | and / double ampersand / logical and |
| `&a` | アンド・エー / アドレス・エー | address of a / ampersand a |
| `int* p` | イント・ポインタ・ピー | int pointer p / int star p |
| `*p` | アスタリスク・ピー / アスタ・ピー | star p / dereference p |
| `->` | アロー | arrow |
