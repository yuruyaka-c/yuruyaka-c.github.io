### 1.1.5 puts 関数を使って文字を表示する

```c title="puts 関数を使うコード"
#include <stdio.h>

int main()
{
	puts("Apple");
}
```

### 1.1.6 puts の前の大きな空白は「インデント」

```c title="puts 関数の前にあるインデント"
#include <stdio.h>

int main()
{
	puts("Apple");
}
```

### 1.1.7 main 関数の最後で「正常終了」を伝える

```c title="正常終了の報告を明示的に行うコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	return 0;
}
```

### 1.1.8 return 0; は省略できる

```c title="正常終了の報告を自動的に行うコード"
#include <stdio.h>

int main()
{
	puts("Apple");
}
```

## 1.2 文字列を出力する

### 1.2.1 複数の文字列を出力する

```c title="複数の puts 関数を使うコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
}
```


### 1.2.2 順番を変えてみる

```c title="puts 関数の並びを入れ替えたコード"
#include <stdio.h>

int main()
{
	puts("Banana");
	puts("Apple");
}
```


### 1.2.3 さらに文字列を出力する

```c title="puts 関数を増やしたコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
	puts("Cat");
}
```


### 1.2.4 インデントをそろえる

```c title="インデントが不ぞろいなコード"
#include <stdio.h>

int main()
{
	puts("Apple");
 puts("Banana");
  puts("Cat");
puts("Dog");
}
```

```c title="インデントがそろっているコード"
#include <stdio.h>

int main()
{
	puts("Apple");
	puts("Banana");
	puts("Cat");
	puts("Dog");
}
```


### 1.2.5 練習

```c title="文字を並べて長方形を描くコード"
#include <stdio.h>

int main()
{
	puts("**********");
	puts("*        *");
	puts("*        *");
	puts("*        *");
	puts("**********");
}
```

```c title="文字を並べて三角形を描くコード"
#include <stdio.h>

int main()
{
	puts("    *");
	puts("   ***");
	puts("  *****");
	puts(" *******");
	puts("*********");
}
```


### 1.2.6 文字列の途中で改行する

```c title="文字列の中で改行文字を使うコード"
#include <stdio.h>

int main()
{
	puts("Apple\nBanana\nCat");
	puts("Dog");
}
```


### 1.2.7 改行を連続させる

```c title="たくさん改行するコード"
#include <stdio.h>

int main()
{
	puts("Apple\n\nBanana\n\n\nCat\n");
	puts("Dog");
}
```


## 1.3 特殊な文字のエスケープ

### 1.3.1 改行

```c title="文字列の中で改行文字を使うコード"
#include <stdio.h>

int main()
{
	puts("He waited.\n\nNo one came.");
}
```

### 1.3.2 タブ空白

```c title="文字列の中でタブ空白を使うコード"
#include <stdio.h>

int main()
{
	puts("1\tJanuary");
	puts("2\tFebruary");
	puts("3\tMarch");
	puts("12\tDecember");
}
```

### 1.3.3 ダブルクォーテーション

```c title="文字列の中でダブルクォーテーションを使うコード"
#include <stdio.h>

int main()
{
	puts("She found the \"key\"!");
}
```

### 1.3.4 バックスラッシュ

```c title="バックスラッシュを出力するコード"
#include <stdio.h>

int main()
{
	puts("/(^o^)\\");
}
```


### 1.3.5 練習

```c title="エスケープシーケンスの練習"
#include <stdio.h>

int main()
{
	puts("/(^o^)\\n\\(^o^)/");
}
```

```c title="タブ空白で整列された表を出力するコード"
#include <stdio.h>

int main()
{
	puts("|0\t|0\t|");
	puts("|1\t|1\t|");
	puts("|10\t|2\t|");
	puts("|11\t|3\t|");
}
```


## 1.4 コンパイル時の警告とエラー

### 1.4.1 エラーが出るコード

```c title="❌ 誤り: 文末にセミコロン ; が無いコード"
#include <stdio.h>

int main()
{
	puts("Apple")
}
```


### 1.4.2 複雑なエラーが出るコード 1

```c title="❌ 誤り: 必要なダブルクォーテーションが無いコード"
#include <stdio.h>

int main()
{
	puts(Apple);
}
```

### 1.4.3 複雑なエラーが出るコード 2

```c title="❌ 誤り: main 関数の閉じかっこ } が無いコード"
#include <stdio.h>

int main()
{
	puts("Apple");
```

### 1.4.4 警告が出るコード

```c title="⚠️ 誤り: 存在しないエスケープシーケンスを使うコード"
#include <stdio.h>

int main()
{
	puts("Apple\mBanana");
}
```
