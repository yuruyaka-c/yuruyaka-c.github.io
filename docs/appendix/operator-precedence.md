# 演算子の優先順位

## 主要な演算子の優先順位と結合規則

| 優先順位 | 演算子 | 結合規則 |
|:------:|--------|:--------:|
| 1（高い） | `a++` `a--` `()` `[]` `.` `->` | 左結合 | 
| 2 | `++a` `--a` `+a` `-a` `!a` `~a` `(type)a` `*a` `&a` `sizeof a` | **右結合** |
| 3 | `*` `/` `%` | 左結合 |
| 4 | `+` `-` | 左結合 |
| 5 | `<<` `>>` | 左結合 |
| 6 | `<` `<=` `>` `>=` | 左結合 |
| 7 | `==` `!=` | 左結合 |
| 8 | `&` | 左結合 |
| 9 | `^` | 左結合 |
| 10 | `|` | 左結合 |
| 11 | `&&` | 左結合 |
| 12 | `||` | 左結合 |
| 13 | `?:` | 右結合 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `|=` | **右結合** |
| 15（低い） | `,` | 左結合 |

## 優先順位とは
- 演算子の優先順位は、数値が小さいほど高くなる
- 優先順位が高い演算子ほど、周囲の式と先に結合する。その結果、かっこで囲んだ場合と同じように式が解釈される

```c
a + b * c == d
```
　↓
```c
(a + (b * c)) == d
```

## 結合規則とは

- 演算子の優先順位が同じ場合に、左から右へまとめるか、右から左へまとめるかを決めるルール
- **左結合**と**右結合**の 2 種類がある

### 左結合
- 優先順位が同じ演算子が並んだ場合、左側から順にまとまる

```c
a + b - c + d
```
　↓
```c
((a + b) - c) + d
```

### 右結合
- 優先順位が同じ演算子が並んだ場合、右側から順にまとまる

```c
a = b = c = d
```
　↓
```c
a = (b = (c = d))
```
